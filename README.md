# Word 单行阅读工具

Windows 桌面工具：导入 TXT，在 Microsoft Word 窗口底部一次显示一行，并自动记住阅读位置。

## 功能

- 自动将长段落拆为适合阅读条宽度的单行。
- 自定义显示 / 收起快捷键、上一行和下一行按键。
- 自定义字体与字号，并提供预览。
- 自动保存每本书的阅读进度。
- 支持常见 UTF-8、UTF-16、UTF-32 和 GB18030 / GBK 文本。
- 纯白无边框阅读条，两侧内缩，显示时保留 Word 的最大化状态。

## 下载与使用


1. 点击「导入 TXT」选择小说。
2. 打开一个 Word 文档。
3. 点击「开始阅读」。

默认按键：

| 按键 | 功能 |
| --- | --- |
| Ctrl + ← | 显示 / 收起阅读条 |
| ↑ / ↓ | 上一行 / 下一行 |
| Ctrl + O | 导入 TXT |
| Ctrl + Home / Ctrl + End | 跳到开头 / 末尾 |

翻行前先点击阅读条，或使用快捷键唤出阅读条。点击启动窗口或托盘菜单中的「阅读设置」，可以修改按键、字体和字号；点击「保存并应用」即时生效。

小说原文件保持原样。阅读进度保存在程序旁的「阅读记录」文件夹，自定义选项保存在「阅读设置.xml」。升级时退出旧版，替换 exe，并保留这些文件。

更多说明见 [使用说明](使用说明.md)。

## 运行环境

- Windows 桌面。
- Microsoft Word 桌面版。
- .NET Framework 4.x，需包含 Windows Forms 与 WPF UI Automation 组件。

单个 TXT 最大 64 MB。使用 Word 的「页面视图」可以获得纸张边界定位；未取得页面边界时使用居中的较窄阅读条。

## 从源码构建

源码位于 `src/`。`build.ps1` 使用 Windows 中的 .NET Framework C# 编译器，产物为 `dist/单行阅读.exe`。

```powershell
.\build.ps1
```

无需安装 Office 宏或修改 Word 文档。
